# Лабораторная №2. Виртуальный датчик печи

Само решение в `lab2.ipynb`. Здесь только как его запустить и что в итоге получилось.

## Как запустить

Нужен Python 3.10. Файлы `data_train.csv`, `target_train.csv`, `data_test_small.csv` и `target_test_small.csv` лежат в этой же папке.

```bash
cd lab2
python3.10 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m ipykernel install --user --name lab2venv --display-name "Python lab2"
jupyter notebook lab2.ipynb
```

В Jupyter выбрать ядро Python lab2 и прогнать ячейки сверху вниз. Запускать надо из папки `lab2`: ноутбук ищет данные в текущей папке.

Считается около минуты. Картинки в файле уже есть, для чтения можно не перезапускать.

Тестовую цель я не трогаю, пока выбираю признаки и параметры. Сначала смотрю хвост обучения, с 24 августа. Потом один раз считаю тест, с 7 октября по 4 ноября.

## Что получилось

Концентрация в файле без единиц, примерно от 0.11 до 0.72, среднее около 0.25. Пробы почти всегда в нечётный час, обычно раз в 2 часа. Прошлый замер беру, только если ему уже больше 15 минут (лаборатория успела ответить) и меньше 6 часов (дальше он слишком старый).

| Модель на тесте | MAE | RMSE | MAPE, % | WAPE, % |
| --- | ---: | ---: | ---: | ---: |
| Среднее обучения | 0.080 | 0.092 | 48.5 | 38.3 |
| Повтор прошлого замера | 0.060 | 0.080 | 29.9 | 28.5 |
| Ридж (alpha 300) | 0.052 | 0.068 | 28.8 | 25.0 |
| Случайный лес | 0.058 | 0.072 | 32.0 | 27.4 |
| Бустинг, глубина 3 | 0.053 | 0.070 | 28.5 | 25.3 |
| Бустинг без прошлого замера | 0.063 | 0.078 | 35.1 | 30.2 |

Планка — повтор прошлого замера, MAE 0.060. Ридж и бустинг лучше него примерно на 0.007. Лабораторию это не заменяет, но между пробами точнее, чем оставлять старое значение. На хвосте обучения выбран бустинг, на тесте ридж лучше на 0.0007, параметры после теста не менял. Без прошлого замера MAE 0.063: каналы только поправляют лабораторию.

Знак шага за 2 часа модели берут примерно в половине случаев. Смотреть стоит уровень. По важности почти всё держит прошлый замер. SHAP после него выделяет каналы 12, 15 и часовой максимум `telemetry_0`. Это связь, не совет крутить канал. Все три модели учатся меньше секунды.

## Как совместил данные

Время в `target` — это время отбора пробы, не время, когда результат пришёл из лаборатории. Сдвиг на 10–15 минут корреляцию не улучшил, поэтому цель я не сдвигал. Задержку учитываю иначе: замер моложе 15 минут в признаки не кладу, его ещё нет на руках. Каналы 0–11 идут каждую минуту. Каналы 12–15 пишутся раз в два часа, в чётный час. Между ними держу последнее значение и не заполняю из будущего. Ноль 20 марта в обучение не беру, он похож на сбой анализа.

## Чего модель не умеет

Не говорит, какой канал за что отвечает. Печью не управляет. Тест — один осенний месяц, на другой кампании ошибка может быть другой. Ноль концентрации я счёл плохим анализом. Если на заводе такой ноль бывает нормальным, это правило надо убрать.
